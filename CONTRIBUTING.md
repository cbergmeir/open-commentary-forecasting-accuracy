# Contributing Guidelines

Thank you for contributing to this open academic paper.

## Ways to contribute
- Fix typos or improve clarity
- Add references or related work
- Propose new sections or subsections
- Improve proofs, experiments, or explanations

All contributions must be made via **pull requests**.

---

## Authorship policy

Authorship follows standard academic norms.

A contributor qualifies for **co-authorship** if they:
- Make a substantial intellectual contribution
- Contribute text, theory, analysis, or interpretation
- Participate in at least one major revision cycle

Minor contributions (typos, formatting, small clarifications)
will be acknowledged but do not automatically imply authorship.

Final authorship decisions are documented transparently in the repo.

---

## Workflow

1. Fork the repository
2. Create a branch
3. Edit Markdown files in `paper/sections/`
4. Submit a pull request
5. Participate in review if requested

All discussions happen openly in GitHub.

---

## Style guidelines

- Write in clear academic English
- Use Markdown (Pandoc-flavored)
- Use LaTeX math: `$...$` and `$$...$$`
- References must go in `references.bib`

---

## Licensing

By submitting a contribution, you agree that it is released
under the repository license.
